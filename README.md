# Doctor Znanie (Доктор Знание)

An educational game about the human body, developed by a team of three using Unity and published for web browsers through WebGL.

The player takes on the role of Doctor Znanie and helps cure a patient infected by a new virus. By completing challenges focused on five organs — the heart, brain, lungs, stomach, and liver — the player collects the five parts of a serum.

Each organ level combines educational videos, puzzles, mini-games, and quizzes.

## Play the Game

[Play Doctor Znanie](https://motivate-bg.online/interngames/doktorznanie/)

The game and its educational content are in Bulgarian.

## Features

- Five organ levels with different educational challenges.
- Three difficulty settings.
- Organ unlocking, rewards, and serum collection.
- User registration, login, and saved progress.
- A leaderboard for comparing player scores.
- Audio, brightness, and colour accessibility settings.
- Educational video playback integrated into the gameplay.
